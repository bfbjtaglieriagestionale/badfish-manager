BADFISH MANAGER v5 - ACCOUNT GOOGLE SALVATO
===========================================

COSA CAMBIA
- Al primo avvio Badfish chiede l'email Google da usare per Drive.
- Spunta "Salva questo account..." (attiva di default) per ricordarla.
- L'email viene salvata sul dispositivo e nella configurazione del gestionale.
- Le connessioni successive usano quell'email come login_hint Google.
- Badfish verifica che l'account Drive collegato corrisponda all'email salvata.
- Da Impostazioni puoi cambiare o dimenticare l'account.
- Corretto il logo Badfish in alto a sinistra.
- Corretto il precedente problema blob.text.
- Cache PWA aggiornata a v5 con strategia network-first.

AGGIORNAMENTO SU GITHUB
1. Estrai questo ZIP.
2. Nel repository badfish-manager carica TUTTI i file/cartelle contenuti qui.
3. Sostituisci i file esistenti e fai Commit changes.
4. Attendi GitHub Pages.
5. Per forzare l'uscita dalla vecchia cache apri una volta:
   https://bfbjtaglieriagestionale.github.io/badfish-manager/?v=5
6. Se avevi installato la PWA sul telefono, chiudila completamente e riaprila.

ACCOUNT GOOGLE
La prima volta inserisci l'email Gmail dedicata a Badfish e premi "Salva e collega".
Dopo il salvataggio l'app non richiede più l'email ad ogni avvio.
