# Badfish Manager v7.2 — Clienti

Nuova sezione Clienti: elenco, ricerca, anagrafica, recapiti e note, elenco ordini e file per cliente e somma delle ore delle sessioni e dei cronometri.

Le commesse vecchie sono abbinate al nome normalizzato, senza riscrivere i dati al caricamento. Quando si crea una scheda cliente, le commesse corrispondenti vengono collegate tramite ID stabile. Modificare il nome dalla scheda aggiorna le commesse abbinate. Il conteggio ore include sessioni storiche e timer in corso o in pausa.

I record clienti sono inclusi nel database esistente e nel merge tra cache e Google Drive. Non sostituisce un backup Drive. Necessari test reali di login, sincronizzazione e cache PWA.
